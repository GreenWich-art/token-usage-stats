# Token 用量统计

本机 AI 编程工具的用量看板：读取你电脑上已有的会话日志，统计 token 用量、按官方 API 单价折算的成本、套餐额度与积分。

**全部在本机解析，不上传任何内容，不修改你的文件。**

## 能看什么

- **用量**：按天、按模型、按会话、按小时统计输入 / 输出 / 缓存读取；含今日用量与今日会话
- **成本**：按厂商官网的 API 单价逐次折算，可横向比较不同客户端、订阅与限免渠道
- **额度**：Codex 的 5 小时 / 7 天窗口、Cursor 与 GitHub Copilot 的额度桶、智谱 GLM 等 Coding Plan 的 5 小时 / 周 / 月窗口
- **余额与积分**：Kimi 开放平台、DeepSeek 开放平台的账户余额；WorkBuddy 的积分消耗
- **不区分客户端来源**：WorkBuddy、Codex、Claude Code、DeepSeek 的记录合并统计，也可分别查看

## 快速开始

要求：macOS，已安装 `python3`（系统自带或用 `brew install python3`）。**无第三方依赖**，只用 Python 标准库。

1. 下载本仓库（`Code → Download ZIP`）并解压
2. 双击 `start.command`（首次运行若被拦，右键 → 打开）
3. 浏览器会自动打开 <http://127.0.0.1:8791/>

命令行方式：

```bash
python3 token-usage-server.py --port 8791
```

关闭终端窗口即停止。服务只监听 `127.0.0.1`，局域网内其他设备访问不到。

## 数据从哪来

| 客户端 | 读取位置 | 说明 |
|---|---|---|
| WorkBuddy | `~/.workbuddy/projects/*/*.jsonl` | 会话日志 |
| Codex | `~/.codex/sessions/` | rollout 日志 |
| Claude Code | `~/.claude/projects/` | 会话日志 |
| DeepSeek Harness | `~/.dsh/sessions/` | 会话日志 |

只读取上述路径下的会话文件；找不到的客户端会显示为「未找到」，不影响其他来源。

## 隐私与数据

- **只读**：仅读取日志文件，不写入、不改动
- **不上传**：没有任何遥测或云端请求；页面无法向外发请求（CSP 限制为同源）
- **不碰凭据**：不读取其他应用的凭据文件（如 `~/.dsh/.credentials.yaml`）、不访问系统钥匙串
- **出网仅在显式开启后**：只有你打开「厂商额度查询」，才会向厂商接口查询额度；端点写死在代码里，不会连接任意地址

## 额度查询

在「额度与积分」区块右上角点「厂商额度查询」即可开启。开启后：

- 智谱 GLM Coding Plan 的额度：自动使用你在 WorkBuddy 里配置的模型 Key
- Kimi、DeepSeek 的账户余额：需要在配置文件中填入对应的 API Key

配置文件在 `~/.token-usage-stats/online.json`，**首次运行会自动生成**，权限为 `600`（仅本人可读写），其中 `api_keys` 段保留了占位符：

```json
"api_keys": {
  "deepseek": ""
}
```

在引号里填入你的 Key（保留键名），保存后自动生效，无需重启。Key 只用于向对应厂商查询余额，不会写入日志、不会出现在接口响应里。

**暂不支持**：Claude Code 的额度（本地没有可用数据）；WorkBuddy 的账户剩余积分与到期时间（数据在服务端）。

## 成本口径

成本是**等价价值**：把每次调用的输入 / 输出 / 缓存按厂商官网的 API 付费单价折算后相加，因此订阅套餐内或限免渠道的用量也按同一把尺子计价，可以横向比较。

它**不等于你的实际支出**。匹配不到单价的模型会标为「未定价」并单列，不会按 0 元混进合计。

## 常见问题

**端口被占用**
关掉占用 `8791` 的程序，或换端口：`python3 token-usage-server.py --port 8800`。

**页面显示没有数据**
确认对应工具的日志目录存在且有会话记录；也可以在「明细与诊断」里展开「数据来源明细」查看每个目录读到了多少文件。

**Codex 的数字停在几天前**
Codex 的额度窗口来自本机日志的最后一次调用，几天没用 Codex CLI 就会停在那天，属正常。

**为什么只有「未定价」没有金额**
该模型的公开单价没查到（多为路由别名或内部代号），或调用量极低未单独收录。

## 已知限制

- 旧版页面 `/report` 未做完整的 HTML 转义，已用最严 CSP 禁止脚本执行；建议优先使用主页
- 额度数据来自本机记录与厂商接口，两者不一致时以厂商接口为准
